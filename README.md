# Chat_UI
Chat_UI是最迅速、最轻量化、最通用、无依赖的LLM聊天客户端，仅2个文件，总共小于100kb，有浏览器就能用。支持几乎全部的参数调整、全部的API格式；支持多模态交互；支持历史记录导出与快速编辑。
Chat_UI is the fastest, lightest, most versatile, and zero-dependency LLM chat client available. Comprising just two files totaling under 100 KB, it runs instantly anywhere with a web browser. It offers comprehensive parameter tuning and full compatibility with all standard API formats, along with native support for multimodal interaction, rapid history reading, and export.
Chat_UIは、最速・最軽量・高汎用で依存関係ゼロのLLMチャットクライアントです。構成ファイルはわずか2つ（合計100KB未満）で、ブラウザさえあればどこでも即座に動作します。ほぼすべてのパラメータ調整や全APIフォーマットに完全対応し、マルチモーダル対話をはじめ、会話履歴のエクスポートや迅速な編集機能も網羅しています。

使用方法：分别下载主html文件与config文件，在config文件（配置项见文件内名字）中完成配置后，启动html并读取config文件，然后就可以开始聊天了。如果需要保存历史记录，轻点击导出按钮；如需继续之前的聊天和历史，请导入历史记录。历史记录不会自动留存，页面关闭即消失。
How to Use: Download the main HTML file and the configuration file separately. Once you have configured your settings in the config file (guided by the parameter names within), open the HTML file, load the configuration, and you are ready to chat. To save your chat history, simply click the export button; to resume a previous conversation, import your saved history file. Please note that chat history is not retained automatically and will be cleared once the page is closed. As the project is currently under active development, it is presently available only in Simplified Chinese, with support for additional languages planned for future releases.
使用方法： メインのHTMLファイルと設定（config）ファイルをそれぞれダウンロードします。設定ファイル内の記載に沿って設定を完了させた後、HTMLファイルを起動して設定ファイルを読み込むことで、すぐにチャットを始められます。会話履歴を保存したい場合は「エクスポート」ボタンをクリックし、前回のやり取りを再開したい場合は履歴ファイルを「インポート」してください。なお、会話履歴は自動保存されず、ページを閉じると消失しますのでご注意ください。現在開発中のため、当面は簡体字中国語版のみの提供となりますが、多言語対応につきましては今後のアップデートにて順次実装予定です。
